# DFM Foundations

## Definition

Designed Functional Maturity treats creation as an intentionally specified and initialized system whose components may be deployed in states already capable of performing their intended functions.

Functional maturity concerns operational state. It does not by itself entail that every retrodictable antecedent state was instantiated as elapsed history.

## Current hard-core candidates

Pending explicit decision-register ratification:

1. creation is intentional rather than metaphysically undirected;
2. the created system begins from an initialized boundary;
3. initialized systems may possess immediate functional maturity;
4. present observations and reconstructed antecedent histories are categorically distinct epistemic products;
5. DFM remains accountable to observed physical state;
6. initialization must be constrained rather than arbitrary;
7. model comparison uses symmetric evidential and methodological standards.

Specific cosmological, geological, radiogenic, biological, or chronology-resolving mechanisms belong to the protective belt unless explicitly promoted.

## Categories

DFM distinguishes revealed claims, methodological principles, empirical observations, model-conditioned reconstructions, and revisable hypotheses. These categories must remain visible in substantive arguments.

## Relationship to BWM

DFM is a component research programme within BWM. BWM owns integrated world-model architecture. DFM owns the functional-maturity and initialization framework and its empirical development.
