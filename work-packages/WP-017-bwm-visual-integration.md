# WP-017: Biblical WorldModel Visual Integration

**Status:** Executed  
**Type:** Public-site visual integration
**Depends on:** WP-016

## Objective
Align the DFM Pages site with the established Biblical WorldModel visual system while retaining a distinct DFM technical identity.

## Source system
The BWM public site and repository establish the parent visual language: navy/cream/cyan palette, Georgia display typography, restrained uppercase kickers, thin cyan rules, landscape imagery, compact cards, and explicit research-status communication.

## Implementation
- Adopt BWM-derived color tokens and typography.
- Add BWM-style split wordmark treatment for DFM.
- Reuse the published BWM hero landscape and footer landscape as shared portfolio imagery.
- Retain a darker technical treatment for DFM.
- Add explicit parent-programme bridge to the Biblical WorldModel.
- Preserve mobile-first behavior and existing DFM content hierarchy.

## Provenance
Shared imagery is referenced from the published BWM site rather than duplicated, preserving the BWM graphics library as the source asset owner. DFM remains the source of truth for DFM technical claims.
