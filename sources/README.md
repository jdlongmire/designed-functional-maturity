## Use discipline

1. Preserve source transcripts without silently rewriting speaker claims.
2. Treat transcript statements as claims by the named speakers, not as established findings.
3. Trace technical claims to primary literature before promoting them into the DFM evidence ledger.
4. Separate observations from interpretation, model assumptions, auxiliary assumptions, boundary/initialization conditions, and inferred history.
5. Record counterevidence and adverse likelihoods under the same standard applied to evidence favorable to DFM.
6. For Bayesian use, specify the competing hypotheses and likelihood-bearing evidence explicitly. Do not assign evidential weight merely because an observation is compatible with a model.

## Priority extraction from this source

The highest-priority DFM research thread is the Oklo exchange because it supplies a concrete natural system in which a highly organized functional state arose through an identifiable physical process. It therefore provides a useful severe test against simplistic design inference while simultaneously exposing the historical-inference question central to DFM: what follows from the observed residual state itself, and what follows only after adopting a reconstruction model and initialization assumptions?

Secondary extraction priorities are the discussion of abductive inference, probabilistic resources, model dependence in cosmology, prediction versus retrodiction, and the distinction between negative critique and positive causal evidence.
