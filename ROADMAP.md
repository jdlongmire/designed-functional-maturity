# DFM Research Roadmap

## Current objective

Move DFM from a conceptual framework to a constrained, quantitatively testable research programme.

## Phase 1: Programme foundation

**Status: baseline established**

- Define hard core and heuristics.
- Separate observation, retrodiction, and actual history.
- Define historical age and retrodictive age.
- Establish no-smuggling and no-free-lunch rules.
- Establish ordinary-decay default.
- Establish coherent radiogenic initialization as a research hypothesis.

## Phase 2: Radiogenic severe tests

**Status: active**

Priority order:

1. U-238/Pb-206 and U-235/Pb-207 dual-system zircon concordance.
2. U-Th-Pb coupling and terrestrial heat-budget consistency.
3. Rb-Sr and Sm-Nd as non-heat-centric concordance tests.
4. K-Ar/Ar-Ar known-age calibration and post-initialization event chronometry.
5. Lu-Hf and Re-Os as severe tests.
6. Extinct radionuclide systems as a dedicated work package.

Deliverables:

- quantitative Radiogenic Coherent Initialization Matrix;
- primary-source evidence ledger;
- initialization degrees-of-freedom analysis;
- known-age calibration dataset;
- concordance/discordance model;
- explicit failure criteria.

## Phase 3: Cosmological initialization

**Status: developing**

- Formalize Day 4 deployment boundary.
- Separate observed redshift from inferred travel/development history.
- Model light propagation and “starlight in transit” precisely.
- Treat SN 1987A and supernova-remnant observations.
- Map nucleosynthetic products to functional-state requirements.
- Quantify low-entropy boundary conditions.
- Test mature high-redshift structures against preregistered DFM expectations.

## Phase 4: Earth-system initialization and disturbance

**Status: planned**

- Couple thermal state, radiogenic inventory, mantle/crust partition, hydrosphere and atmosphere.
- Distinguish initialization state from subsequent catastrophic disturbance.
- Integrate Flood-related auxiliaries only when independently constrained.
- Build pristine-state versus disturbed-state inference rules.

## Phase 5: Comparative appraisal

**Status: planned**

- Build a common evidence ledger for DFM and conventional deep-time reconstruction.
- Score independent constraint, auxiliary load, predictive novelty, explanatory reach, and unresolved anomalies.
- Perform Bayesian sensitivity analyses where priors and likelihoods can be responsibly specified.
- Publish unresolved burdens rather than suppress them.

## Immediate next gate

The immediate technical gate is a quantitative U-Pb case study.

The case study must attempt to derive or constrain the dual U-Pb concordance structure from a common initialized state without using the conventional target age as an input.

A negative result is informative. If coherent initialization cannot account for the observed structure without age-target fitting, the current radiogenic auxiliary must be revised or downgraded.
