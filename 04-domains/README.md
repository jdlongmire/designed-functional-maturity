# DFM Domain Investigations

Domain work applies the canonical DFM framework to empirical problem spaces. Domain hypotheses remain revisable unless explicitly promoted through the decision process.

## Current domain tracks

### Radiometrics
WP-002 is the active source. Ordinary measured decay behavior is the prospective default. Accelerated decay is neither DFM hard core nor presumed by a short chronology.

### Cosmology
WP-003 develops the Supernova Functional-State Hypothesis and uses SN 1987A as a high-information stress test. The hypothesis remains protective-belt research.

Additional domain directories should be created when they have content to own, rather than as empty taxonomy.
